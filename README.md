# BELENTANI / ARCHIVO VIVO

Archivo de la obra de Belentani: piezas, proceso y memoria.

## Qué es

No es un portfolio al uso ni un sitio comercial. Es el **archivo vivo**: lo que se hizo, cómo
se hizo y en qué orden. La obra tiene un antes y un después, y esto lo conserva.

En línea: <https://belentani7.github.io/belentani-artista-unified/>
