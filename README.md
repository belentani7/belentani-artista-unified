# BELENTANI / ARTISTA — Archivo Unificado

Nueva entrada unificada para el universo artístico de Belentani. Los repositorios originales no se han modificado: cada snapshot se conserva dentro de `archive/` para consulta y preservación.

## Experiencia

- `index.html`: galería 3D y portada unificada.
- En cada carga se elige una pieza destacada de forma determinista según la hora, con opción de barajar.
- Las tarjetas enlazan a los HTML conservados en `archive/`.
- La galería funciona sin build ni servidor: basta abrir `index.html` o publicarla como sitio estático.

## Fuentes preservadas

Incluye snapshots de los repositorios artísticos relacionados encontrados en la cuenta de GitHub. Los proyectos educativos, privados y no artísticos se han dejado fuera deliberadamente.
